On the Subject of Layer Keys

WE NEED TO GO DEEEEEPEEEEERRRRRR......

  • This module contains 4 letterd keys and a number display.
  • If the number display is red, you are looking at the wrong manual.

The First Layer.

  • If the serial number contains "A" or "Z" use the first of those two that appears in the serial number.
  • Otherwise, let n = 2.
    • Add 6*(the reading order position of the A key, 0-indexed).
    • Add 2*(the reading order position of the B key, 0-indexed).
    • If the B key is after the A key, subtract 2.
    • If the C key is after the D key, add 1.
  • Use the letter that is at position n (A1Z26).
